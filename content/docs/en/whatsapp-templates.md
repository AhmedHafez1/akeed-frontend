## Overview

Your WhatsApp template is the customer-facing voice of your confirmation flow.

A clear template improves response speed, reduces confusion, and helps customers confirm or cancel quickly.

## Why Template Quality Matters

Customers decide in seconds whether to respond.

If your message is unclear, too long, or in the wrong language, replies drop.

Good templates are:

- short and direct,
- easy to understand,
- aligned with your audience language,
- clear about what action is needed.

## Languages and Variants

Akeed supports Arabic and English templates with multiple styles.

| Language | Available styles |
| --- | --- |
| Arabic | Standard, Egyptian, Gulf, Short |
| English | Friendly, Professional, Direct, Short |

## How To Choose the Right Style

### Arabic stores (general)

Start with **Standard**.

### Egyptian-heavy customer base

Try **Egyptian** for more natural tone.

### Gulf-heavy customer base

Try **Gulf**.

### High-volume, fast ops

Try **Short** for quicker scanning and faster replies.

### English audiences

- **Friendly**: conversational tone.
- **Professional**: formal business tone.
- **Direct**: concise and action-first.

> [!INFO]
> If you are unsure, start with Standard (Arabic) and Friendly (English), then optimize based on response metrics.

## Best Practices for Better Replies

1. Keep the message focused on one decision: confirm or cancel.
2. Avoid extra promotional text inside confirmation templates.
3. Make sure order number and total are easy to scan.
4. Use language your customer actually speaks day-to-day.
5. Re-check template after changing audience targeting or market.

## A/B Testing Approach (Simple)

Use a weekly testing rhythm:

1. Pick one template change only.
2. Run it for 5–7 days.
3. Compare:
   - reply rate,
   - confirmation rate,
   - no-reply volume.
4. Keep winner, then test next change.

Do not change multiple settings at once, or you will not know what improved performance.

## Common Mistakes

| Mistake | Better Approach |
| --- | --- |
| Picking a style based on preference only | Pick based on customer response data. |
| Using long wording for all stores | Use short variants when speed and clarity are more important. |
| Ignoring language-market fit | Match message language and tone to your main customer segment. |
| Changing template + timing + follow-up together | Test template changes separately. |

## Troubleshooting

### Customers read but do not click confirm/cancel

- Try a clearer and shorter variant.
- Re-check whether the action request is explicit.
- Use a style closer to customer dialect.

### Confirmation rate dropped after template change

- Roll back to last stable variant.
- Test one new variant for a full week.

### Too many no-reply cases after template update

- Pair template optimization with follow-up enabled.
- Re-check send timing and quiet hours.

## FAQ

### Should I use the same template for all customers?

Not always. If your audience segments differ by region/language, use the best-fitting variant.

### Is shorter always better?

Not always. Short is great for speed, but clarity is the top priority.

### How often should I change templates?

Only when data suggests improvement potential. Frequent random changes make performance hard to read.

### Where can I preview template output?

Use the message preview section in settings.
