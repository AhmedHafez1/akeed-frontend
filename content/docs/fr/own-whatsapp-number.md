## Vue d’ensemble

Par défaut, Akeed envoie les confirmations depuis son propre numéro WhatsApp officiel, et vous n’avez rien à connecter. Vous pouvez aussi connecter votre propre numéro WhatsApp Business, pour que les clients reçoivent les confirmations au nom et depuis le numéro de votre entreprise.

Le numéro d’Akeed reste disponible en secours. Tout message que votre numéro ne peut pas encore envoyer part du numéro d’Akeed, et les clients continuent donc de recevoir leurs confirmations.

Vous pouvez connecter un numéro que vous utilisez déjà dans l’application WhatsApp Business sur votre téléphone, ou un numéro qui n’est pas encore sur WhatsApp.

## Avant de commencer

- Vous devez être le propriétaire de la boutique dans Akeed. Seul le propriétaire peut connecter ou déconnecter un numéro.
- Il vous faut un compte Facebook qui gère votre entreprise, ou vous pouvez créer l’entreprise pendant la connexion.
- Si le numéro est dans l’application WhatsApp Business, mettez l’application à jour vers sa dernière version et gardez votre téléphone à portée de main.

## Connecter votre numéro

1. Ouvrez **Paramètres**, puis **WhatsApp**.
2. Choisissez **Connecter votre numéro**. Une page sécurisée s’ouvre dans un nouvel onglet.
3. Terminez-y la connexion avec Facebook : choisissez ou créez votre entreprise, puis choisissez le numéro.
4. Revenez dans Akeed. Les paramètres WhatsApp s’actualisent et indiquent à quel point votre numéro est prêt.

Si le nouvel onglet ne s’ouvre pas, autorisez les fenêtres pop-up pour Akeed dans votre navigateur et choisissez de nouveau **Connecter votre numéro**.

Après la connexion, Akeed prépare les modèles de message pour votre numéro et Meta les examine. Tant qu’un modèle n’est pas approuvé, ses messages continuent de partir du numéro d’Akeed.

### Si le numéro est aussi dans l’application WhatsApp Business

Vous continuez d’utiliser l’application sur votre téléphone pour discuter avec vos clients en tête-à-tête. Ouvrez l’application régulièrement : Meta peut déconnecter un numéro dont l’application est restée inactive pendant environ deux semaines. Dans ce cas, les confirmations partent du numéro d’Akeed jusqu’à ce que vous reconnectiez le numéro.

## Quand votre numéro envoie-t-il ?

Votre numéro n’envoie un message que lorsque ces deux conditions sont réunies :

- le numéro est en bon état : connecté, sans problème de paiement ou de qualité signalé par Meta,
- le modèle exact de ce message est approuvé dans la langue des messages du client.

La disponibilité est vérifiée pour chaque modèle et chaque langue. Votre confirmation en arabe peut être prête alors que le rappel en anglais est encore en cours d’examen. Les paramètres WhatsApp affichent chaque modèle avec sa langue, son statut et le numéro qui l’envoie actuellement.

Les paramètres indiquent aussi le numéro qui a envoyé votre dernier message. Cela montre ce qui s’est passé, pas ce qui va se passer ensuite. Ce qui compte, c’est l’expéditeur actuel de chaque modèle.

### Quand le numéro d’Akeed prend-il le relais ?

Le numéro d’Akeed envoie à la place du vôtre lorsque :

- le modèle n’existe pas dans cette langue, est encore en cours d’examen, a été refusé ou mis en pause par Meta,
- Meta signale un problème de paiement sur votre compte WhatsApp Business ou abaisse la qualité de votre numéro, même si vos modèles sont approuvés,
- votre numéro est déconnecté,
- Meta ne donne pas de réponse claire lorsque Akeed envoie depuis votre numéro.

Votre client reçoit quand même sa confirmation. Les paramètres WhatsApp indiquent la raison pour chaque modèle.

### Revenir à votre numéro

Réglez ce que les paramètres signalent : attendez l’examen du modèle, régularisez le paiement dans votre compte professionnel Meta ou reconnectez un numéro déconnecté. Dès que le modèle est approuvé et que le numéro est en bon état, le message suivant repart de votre numéro. Vous n’avez rien à modifier dans Akeed.

## Combien ça coûte ?

### Crédits prépayés

1 crédit équivaut à 1 EGP.

| Envoyé depuis | Coût par message |
| --- | --- |
| Votre numéro | 1 crédit |
| Le numéro d’Akeed | 2 crédits |

Si votre solde ne couvre pas le coût complet d’un message de secours depuis le numéro d’Akeed, le message est quand même envoyé et utilise ce qui reste.

### Forfaits Shopify

Une fois votre numéro connecté, votre forfait comporte deux quotas distincts :

| Quota | Taille |
| --- | --- |
| Messages depuis le numéro d’Akeed | Les messages inclus dans votre forfait |
| Messages depuis votre numéro | Trois fois les messages inclus dans votre forfait |

Les deux quotas se renouvellent ensemble au début de chaque période de facturation. Un message depuis votre numéro utilise le quota de votre numéro ; une fois celui-ci épuisé, il utilise 1 message du quota d’Akeed. Un message de secours depuis le numéro d’Akeed utilise le quota d’Akeed ; une fois celui-ci épuisé, il utilise 3 messages du quota de votre numéro. Quand les deux sont épuisés, les envois s’arrêtent jusqu’à leur renouvellement.

### Frais de Meta

Meta facture séparément à votre entreprise les messages envoyés depuis votre numéro, selon ses propres tarifs et via votre compte professionnel Meta. Ces frais ne font pas partie de vos crédits ni de votre forfait Akeed. Les messages envoyés depuis le numéro d’Akeed ne vous coûtent aucuns frais Meta.

> [!INFO]
> La facturation indique combien de messages sont partis de chaque numéro, pour que vous puissiez comparer le coût des deux.

## Messages de remerciement

Quand un client confirme ou annule, Akeed peut envoyer un court remerciement. Dans **Paramètres**, puis **WhatsApp**, choisissez si les clients reçoivent un remerciement depuis votre numéro. Il reste activé jusqu’à ce que vous le désactiviez, et votre choix est conservé si vous reconnectez le numéro.

- Un remerciement depuis votre numéro n’entraîne aucuns frais Akeed. Meta peut facturer votre entreprise selon ses propres tarifs.
- Un remerciement depuis votre numéro ne passe jamais par le numéro d’Akeed. Si votre numéro ne peut pas l’envoyer, le client ne reçoit pas de remerciement.
- Les remerciements depuis le numéro d’Akeed ont leur propre réglage et leur propre coût, affichés dans vos paramètres.

## Qui peut faire quoi

| Rôle | Ce qu’il peut faire |
| --- | --- |
| Propriétaire | Connecter, déconnecter et reconnecter le numéro, modifier les remerciements et tout voir |
| Administrateur | Modifier les remerciements et tout voir |
| Lecteur | Voir le numéro, sa disponibilité et les coûts |

## Déconnecter votre numéro

1. Ouvrez **Paramètres**, puis **WhatsApp**.
2. Choisissez **Déconnecter** et confirmez.

À partir de là, les confirmations partent du numéro d’Akeed. Vos commandes et l’historique des messages restent dans Akeed.

> [!WARNING]
> Pour dissocier complètement un numéro qui est aussi dans l’application WhatsApp Business, terminez aussi la déconnexion dans l’application. Dans l’application, ouvrez **Settings**, puis **Account**, puis **Business Platform**, et appuyez sur **Disconnect Account**. Les noms peuvent varier selon la langue de votre téléphone.

Si vous déconnectez d’abord dans l’application WhatsApp Business, Akeed le détecte et fait passer vos confirmations par le numéro d’Akeed.

## Reconnecter votre numéro

Lorsque les paramètres WhatsApp indiquent que votre numéro est déconnecté, le propriétaire peut choisir **Reconnecter** et refaire la connexion avec Facebook. Les messages partent du numéro d’Akeed jusqu’à ce que votre numéro et ses modèles soient de nouveau prêts.
