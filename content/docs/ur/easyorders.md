## جائزہ

اپنا EasyOrders اسٹور ایک بار جوڑیں، اور Akeed ہر نیا کیش آن ڈیلیوری (COD) آرڈر خود بخود وصول کرتا ہے۔ وہ واٹس ایپ پر کسٹمر سے آرڈر کی تصدیق کرتا ہے اور EasyOrders میں آرڈر کی حالت اپ ڈیٹ کرتا ہے۔

آپ کوئی کلید کاپی نہیں کرتے۔ آپ کنکشن کی منظوری EasyOrders کے اندر دیتے ہیں۔

> [!INFO]
> Akeed صرف COD آرڈرز کی تصدیق کرتا ہے۔ ادائیگی کے کسی اور طریقے والے آرڈرز وصول ہوتے ہیں اور چھوڑ دیے جاتے ہیں۔

## شروع کرنے سے پہلے

- آپ اپنے Akeed اکاؤنٹ کے مالک یا ایڈمن ہیں۔
- آپ کا EasyOrders اسٹور فعال ہے۔
- آپ کے Akeed اکاؤنٹ میں پہلے سے آرڈرز کا کوئی اور ذریعہ نہیں۔ ایک اکاؤنٹ اپنے آرڈرز ایک ہی ذریعے سے لیتا ہے۔

## اپنا اسٹور جوڑیں

1. **سائن اپ کرتے وقت EasyOrders چُنیں۔** ای میل کی تصدیق کے بعد آپ کو جوڑنے والی اسکرین پر لے جایا جاتا ہے۔
2. **EasyOrders جوڑیں چُنیں۔** EasyOrders نئے ٹیب میں کھلتا ہے۔ جس اسٹور کو جوڑنا ہے اُس میں سائن اِن کریں، پھر **Accept** چُنیں۔
3. **Akeed پر واپس آئیں۔** کنکشن تیار ہوتے ہی صفحہ خود بخود اپ ڈیٹ ہو جاتا ہے۔
4. **اپنے اسٹور کا ملک اور کرنسی چُنیں۔** EasyOrders آرڈر کی کل رقم کرنسی کے بغیر اور فون نمبر ملک کے کوڈ کے بغیر بھیجتا ہے، اس لیے آپ کے کسٹمرز کو درست پیغام بھیجنے کے لیے Akeed کو دونوں کی ضرورت ہے۔
5. **مفت ٹیسٹ پیغام بھیجیں۔** Akeed آپ کے اپنے واٹس ایپ نمبر پر ٹیسٹ تصدیق بھیجتا ہے۔ اس کے بعد آپ کا اسٹور سیٹ اپ ہو جاتا ہے۔

Akeed، EasyOrders سے صرف دو اجازتیں مانگتا ہے:

- آپ کے نئے آرڈرز پڑھنا،
- کسٹمر کے تصدیق یا منسوخ کرنے پر آرڈر کی حالت اپ ڈیٹ کرنا۔

پیغامات آپ کے کسٹمرز کو Akeed کے واٹس ایپ نمبر سے ملتے ہیں۔ آپ کو اپنے واٹس ایپ نمبر کی ضرورت نہیں۔

> [!WARNING]
> جب تک آپ کسٹمر کے فون کا ملک اور اسٹور کی کرنسی دونوں نہیں چُنتے، آرڈرز کی تصدیق نہیں ہوتی۔

## Akeed آپ کے اسٹور میں کیا لکھتا ہے

| کیا ہوتا ہے | EasyOrders میں |
| --- | --- |
| کسٹمر تصدیق کرتا ہے | آرڈر کی حالت **confirmed** ہو جاتی ہے۔ |
| کسٹمر منسوخ کرتا ہے | آرڈر کی حالت **canceled** ہو جاتی ہے۔ |
| آپ Akeed سے جواب نہ آنے والا آرڈر منسوخ کرتے ہیں | آرڈر کی حالت **canceled** ہو جاتی ہے۔ |
| کسٹمر جواب نہیں دیتا | کچھ نہیں۔ آرڈر پر صرف Akeed میں **جواب نہیں ملا** درج ہوتا ہے۔ |

Akeed کبھی خود سے EasyOrders میں آرڈر منسوخ نہیں کرتا۔ وہ صرف اُس آرڈر کو اپ ڈیٹ کرتا ہے جو ابھی زیرِ التوا ہو: اگر آپ آرڈر کی حالت پہلے ہی بدل چکے ہیں تو Akeed اسے نہیں چھیڑتا۔

## کنکشن کو درست حالت میں رکھیں

کنکشن دیکھنے کے لیے **سیٹنگز** کھولیں، پھر اپنا آرڈرز کا ذریعہ۔

| آپ کیا دیکھتے ہیں | اس کا مطلب | کیا کریں |
| --- | --- | --- |
| آپ کا EasyOrders اسٹور فعال نہیں | EasyOrders کے مطابق اسٹور غیر فعال ہے یا اس کی ادائیگی باقی ہے۔ آرڈرز Akeed تک نہیں پہنچتے۔ | EasyOrders میں اسٹور دوبارہ فعال کریں۔ |
| EasyOrders اب Akeed کی رسائی قبول نہیں کرتا | API کلید EasyOrders سے ہٹا دی گئی ہے۔ | منقطع کریں، پھر اُسی اسٹور کو دوبارہ جوڑیں۔ |
| آرڈرز اس لیے مسترد ہوئے کہ ان کا ویب ہُک سیکرٹ مطابقت نہیں رکھتا تھا | Akeed کے ویب ہُکس EasyOrders میں حذف کر کے دوبارہ بنائے گئے۔ | **ویب ہُک سیکرٹ درست کریں** کھولیں اور **ری سیٹ کریں اور دوبارہ معلوم کریں** چُنیں۔ |

Akeed دونوں ویب ہُکس کو خود محفوظ بناتا ہے: وہ آپ کے پہلے آرڈر کی EasyOrders سے تصدیق کرتا ہے، پھر وہ سیکرٹ محفوظ کر لیتا ہے جو EasyOrders اس کے ساتھ بھیجتا ہے۔ آپ کو کچھ کاپی کرنے کی ضرورت نہیں۔

EasyOrders میں **Akeed** نام کا ٹھیک ایک آرڈرز ویب ہُک اور ایک آرڈر کی حالت والا ویب ہُک رکھیں۔ اگر کوئی ایڈریس دو بار نظر آئے تو اضافی والا حذف کر دیں۔

> [!WARNING]
> جو آرڈرز اسٹور کے منقطع یا غیر فعال ہونے کے دوران آئے وہ بعد میں Akeed کو نہیں بھیجے جاتے۔ اُن آرڈرز کی تصدیق خود کریں۔

## منقطع کرنا اور دوبارہ جوڑنا

سیٹنگز میں **EasyOrders منقطع کریں** چُنیں۔ Akeed اسٹور سے آرڈرز وصول کرنا، اُن کے پیغامات بھیجنا اور اُن کی حالت اپ ڈیٹ کرنا روک دیتا ہے۔ آپ کے پچھلے آرڈرز، نتائج اور استعمال کی ہسٹری محفوظ رہتی ہے۔

Akeed، EasyOrders سے کہتا ہے کہ اُس کے بنائے ہوئے ویب ہُکس حذف کر دے۔ API کلید EasyOrders میں اُس وقت تک رہتی ہے جب تک آپ اسے حذف نہ کریں:

1. EasyOrders میں Settings > Public API کھولیں۔
2. **Akeed** نام کی API کلید حذف کریں۔
3. اگر Akeed بتائے کہ ویب ہُکس حذف نہیں ہوئے تو Webhooks کے تحت **Akeed** نام کا ہر ویب ہُک حذف کریں۔

آپ کسی بھی وقت EasyOrders میں دوبارہ منظوری دے کر اُسی اسٹور کو دوبارہ جوڑ سکتے ہیں۔ اسی اکاؤنٹ سے کوئی دوسرا اسٹور نہیں جوڑا جا سکتا۔ اگر آپ کو اس کی ضرورت ہو تو Akeed سپورٹ سے رابطہ کریں۔

## عام غلطیاں

| غلطی | بہتر طریقہ |
| --- | --- |
| ملک اور کرنسی چھوڑ دینا | دونوں چُنیں۔ ان کے بغیر آرڈرز کی تصدیق نہیں ہوتی۔ |
| دوبارہ جوڑتے وقت کسی اور EasyOrders اسٹور میں سائن اِن کرنا | اُسی اسٹور میں سائن اِن کریں جو پہلے جُڑا ہوا تھا۔ |
| EasyOrders میں Akeed کے ویب ہُکس کو «تازہ» کرنے کے لیے حذف کرنا | انہیں رہنے دیں۔ اگر وہ دوبارہ بنائے گئے ہوں تو Akeed میں ویب ہُک سیکرٹ ری سیٹ کریں۔ |
| یہ توقع رکھنا کہ درستی کے بعد چھوٹے ہوئے آرڈرز آ جائیں گے | وہ امپورٹ نہیں ہوتے۔ اُن کی تصدیق خود کریں۔ |

## مسائل کا حل

### EasyOrders نہیں جُڑا

درخواست منظور نہیں ہوئی، یا اس کی میعاد ختم ہو گئی۔ نئے سرے سے شروع کریں۔ اگر آپ نے Accept چُنا اور پھر بھی ناکامی ہوئی تو ممکن ہے EasyOrders نے Akeed نام کی API کلید اور ویب ہُکس بنا دیے ہوں: دوبارہ کوشش سے پہلے انہیں Settings > Public API کے تحت حذف کریں۔

### یہ اسٹور پہلے ہی کسی اور Akeed اکاؤنٹ سے جُڑا ہوا ہے

ایک اسٹور ایک ہی Akeed اکاؤنٹ سے جُڑتا ہے۔ Akeed سپورٹ سے رابطہ کریں۔

### آرڈرز آنا بند ہو گئے

چیک کریں کہ اسٹور EasyOrders میں فعال ہے، اور سیٹنگز میں اپنا آرڈرز کا ذریعہ کھول کر دیکھیں کہ آرڈرز مسترد تو نہیں ہو رہے۔

### کسی آرڈر کی تصدیق نہیں ہوئی

چیک کریں کہ اس کی ادائیگی کا طریقہ کیش آن ڈیلیوری ہے، کسٹمر کا فون نمبر آپ کے چُنے ہوئے ملک کے لحاظ سے درست ہے، اور آرڈر کی کل رقم صفر سے زیادہ ہے۔

## عام سوالات

### کیا مجھے اپنا واٹس ایپ بزنس نمبر چاہیے؟

نہیں۔ پیغامات Akeed کے واٹس ایپ نمبر سے بھیجے جاتے ہیں۔

### کیا Akeed میرے پرانے آرڈرز امپورٹ کرتا ہے؟

نہیں۔ Akeed اُن آرڈرز کی تصدیق کرتا ہے جو اسٹور جُڑنے کے بعد دیے جائیں۔

### کیا میں بعد میں ملک یا کرنسی بدل سکتا ہوں؟

جی ہاں، سیٹنگز میں اپنے آرڈرز کے ذریعے سے۔

### ادائیگی کیسے ہوتی ہے؟

کریڈٹس سے، ہر اُس اکاؤنٹ کی طرح جو Shopify استعمال نہیں کرتا۔ دیکھیں [Shopify کے بغیر Akeed کا استعمال](/docs/standalone-platform#کریڈٹس-کیسے-کام-کرتے-ہیں)۔
