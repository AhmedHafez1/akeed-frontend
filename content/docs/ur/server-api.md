## جائزہ

Server API کے ذریعے آپ کا سسٹم آرڈرز کو بنتے ہی Akeed کو بھیج سکتا ہے، بجائے اس کے کہ آپ انہیں خود شامل کریں یا فائل سے امپورٹ کریں۔ یہ صفحہ اسٹور کے مالک کے لیے ہے۔ جو ڈویلپر یہ کام کرے گا اُسے مکمل رہنما تحریر چاہیے، جو انگریزی میں ہے۔

**آپ کا سرور ← Akeed کو ایک درخواست ← واٹس ایپ پر تصدیقی پیغام ← نتیجہ ڈیش بورڈ میں**

[ڈویلپرز کے لیے مکمل رہنما تحریر کھولیں (انگریزی میں)](/en/docs/server-api)

> [!INFO]
> یہ API اسٹینڈ اَلون اکاؤنٹس کے لیے دستیاب ہے۔ Shopify اسٹورز کو اس کی ضرورت نہیں کیونکہ اُن کے آرڈرز خودکار طور پر آ جاتے ہیں۔ دیکھیں [Shopify کے بغیر Akeed کا استعمال](/docs/standalone-platform)۔

## یہ API کن کے لیے ہے؟

- وہ اسٹور جس کی اپنی ویب سائٹ یا اپنا آرڈر سسٹم ہو۔
- ڈیلیوری کمپنی یا بیک اینڈ سسٹم جو آرڈرز وصول کرتا ہے اور شپنگ سے پہلے اُن کی تصدیق چاہتا ہے۔
- کوئی بھی سسٹم جو سرور سے HTTPS درخواست بھیج سکتا ہو۔

اگر آپ کے پاس ڈویلپر نہیں تو [آرڈرز کا اجتماعی امپورٹ](/docs/bulk-order-import) استعمال کریں یا آرڈرز ڈیش بورڈ سے شامل کریں۔

## جوڑنے کے مراحل

1. **API کلید بنائیں۔** **سیٹنگز ← API کلیدیں** میں **کلید بنائیں** چُنیں۔ کلید صرف ایک بار نظر آتی ہے، اس لیے اسے فوراً کاپی کر لیں۔
2. **ڈویلپر کو کلید اور بھیجنے کا ایڈریس دیں۔** ایڈریس اسی اسکرین پر **آرڈرز یہاں بھیجیں** کے تحت لکھا ہوتا ہے۔ کلید محفوظ طریقے سے بھیجیں، کسی عوامی گفتگو میں نہیں۔
3. **ڈویلپر [مکمل رہنما تحریر](/en/docs/server-api) کے مطابق کام کرتا ہے۔** پہلی درخواست میں چند منٹ لگتے ہیں۔
4. **نتیجہ دیکھتے رہیں۔** ہر آرڈر آپ کے باقی آرڈرز کے ساتھ **تصدیقات** کی فہرست میں نظر آتا ہے۔

> [!WARNING]
> کلید ایک راز ہے جو صرف آپ کے سرور کے لیے ہے۔ اسے ویب سائٹ کے صفحے، موبائل ایپ یا کسی ایسی جگہ نہ رکھیں جہاں کسٹمر اسے دیکھ سکے۔ جس کے پاس کلید ہو وہ آپ کے اسٹور پر آرڈرز بھیج سکتا ہے۔ اگر آپ کو اس کے افشا ہونے کا شبہ ہو تو اسے **سیٹنگز ← API کلیدیں** سے منسوخ کریں اور نئی کلید بنائیں۔

## آپ کو کیا جاننا چاہیے؟

| سوال | جواب |
| --- | --- |
| کیا آرڈر موصول ہوتے ہی پیغام چلا جاتا ہے؟ | Akeed پہلے آرڈر محفوظ کرتا ہے، پھر آپ کی سیٹنگز کے مطابق پیغام بھیجتا ہے، جیسے خاموش اوقات اور بھیجنے کی تاخیر۔ |
| پیشگی ادا شدہ آرڈرز کا کیا ہوتا ہے؟ | وہ محفوظ ہوتے ہیں اور ڈیش بورڈ میں نظر آتے ہیں، لیکن کسٹمر کو پیغام نہیں جاتا اور کوئی کریڈٹ استعمال نہیں ہوتا۔ |
| اگر سسٹم ایک ہی آرڈر دو بار بھیج دے؟ | دوسرا آرڈر نہیں بنتا، دوسرا پیغام نہیں جاتا اور کریڈٹ دو بار نہیں کٹتا۔ |
| کیا API سے آرڈر میں تبدیلی یا منسوخی ہو سکتی ہے؟ | نہیں۔ API صرف آرڈرز بناتا ہے۔ |
| کسٹمر کا جواب کہاں نظر آتا ہے؟ | ڈیش بورڈ کی **تصدیقات** کی فہرست میں۔ Akeed آپ کے سرور کو اطلاعات نہیں بھیجتا۔ |
| کیا کوئی ٹیسٹ موڈ ہے؟ | نہیں۔ ہر کیش آن ڈیلیوری آرڈر پر اصل پیغام جاتا ہے اور کریڈٹ استعمال ہوتا ہے۔ پہلے اپنے فون نمبر سے آزمائیں۔ |
| آرڈرز کی وصولی کس وجہ سے رکتی ہے؟ | کریڈٹس ختم ہونے، سیٹنگز سے خودکار تصدیق بند کرنے، یا کلید منسوخ کرنے سے۔ |

## مسئلہ پیش آنے پر

Akeed کے ہر جواب میں ایک حوالہ نمبر ہوتا ہے جسے `correlationId` کہتے ہیں۔ ڈویلپر سے کہیں کہ وہ اسے درخواست کے وقت اور خرابی کے کوڈ کے ساتھ [سپورٹ](/support) کو بھیجے۔ کلید خود کسی کو نہ بھیجیں، سپورٹ کو بھی نہیں۔
